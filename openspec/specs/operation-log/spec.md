# Spec — 操作日志

## ADDED Requirements

### Requirement: 登录操作日志

用户登录成功/失败时记录操作日志。

#### Scenario: 登录成功

- **WHEN** 用户登录成功
- **THEN** 记录操作日志，包含用户 ID、操作类型、操作描述、IP 地址、操作时间

#### Scenario: 登录失败

- **WHEN** 用户登录失败
- **THEN** 记录操作日志，包含用户 ID、操作类型、操作描述、IP 地址、操作时间
