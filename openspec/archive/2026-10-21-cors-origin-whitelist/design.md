# Design — CORS 允许来源可配置 + 宽松组合显式告警

- 对应 Proposal: 2026-10-21-cors-origin-whitelist/proposal.md
- 创建日期: 2026-10-21

## 1. 方案概述

```
应用启动
   │
   ├─ CorsConfig#warnOnPermissiveOrigin()（@PostConstruct）
   │     ├─ 配置为空 ───────────────► ERROR「已回退到 *（维持现状）」
   │     └─ 含通配符 + allowCredentials(true)
   │                                  └─► WARN「点名组合 + 风险条件 + 收紧开关」
   │
   └─ CorsFilter（最高优先级）
         └─ allowedOriginPatterns = parseOriginPatterns(easychat.cors.allowed-origin-patterns)
              ├─ "*"（默认）──► 回显任意来源（与改动前逐字一致）
              └─ 白名单 ─────► 只回显名单内来源；名单外**不回显**
```

### 涉及面

| 模块 | 改动 | 职责边界 |
|------|------|----------|
| `config/CorsConfig` | 允许来源可配置 + 启动告警 | 只管 CORS 头；不碰鉴权 |
| `application.properties` | 新增 `easychat.cors.allowed-origin-patterns` | 公共基线，默认 `*` |
| `CorsConfigTest` | +4 例 | 行为测试（含反向制衡） |

## 2. 关键决策

### ADR-001：默认**不收紧**，只把风险变显性

- **选项 A**：直接把默认改成精确白名单 → **拒绝**。
  桌面端渲染层（`file://` 或本地 dev server）与后端**不同源**，收紧后**应用立刻访问不到后端**；
  而「哪些来源算合法」取决于部署形态（本机直连？域名？内网 IP？），仓内无法确定。
- **选项 B（采纳）**：默认仍 `*`（**行为零变化**、零部署风险），
  但①提供收紧开关 ②启动时对宽松组合**显式告警**。
  → 风险从「藏在注释里」变成「每次启动都出现在日志里」，且触发收紧只需改一个配置项。
- **选项 C**：改用 `allowOrigin` 精确列表（替代 pattern）→ 拒绝：会**丢掉**通配能力，
  而桌面端 dev server 的来源带随机端口，通配在开发期是刚需。

### ADR-002：空配置**回退到 `*`** 而不是「拒绝一切来源」

误配（把配置写成空串）时：
- 回退 `*` + 打 **ERROR** → 应用**仍可用**，但配置无效这件事**摆在台面上**；
- 拒绝一切来源 → 应用**立刻不可用**，且症状是「前端报跨域错误」，排障方向容易跑偏。
→ 选前者（**可用性优先 + 日志告警**）。

### ADR-003：告警文案必须写清「**当前为什么不构成暴露面**」

只说「有 CSRF 风险」会被当成噪音忽略。告警须同时给出：
① 现在为什么安全（token 头，凭据不由浏览器自动携带）；
② 什么时候会不安全（改用 Cookie 会话）；
③ 怎么收紧（配置键）。
→ 否则**告警本身**会退化成又一条没人看的日志。

## 3. 风险与边界

| 风险 | 处置 |
|------|------|
| 收紧后桌面端访问不到后端 | 告警文案与 README 均提示「先加白名单」；默认不收紧 |
| 白名单配置写错导致跨域全拒 | 空配置回退 `*` + ERROR 日志（ADR-002） |
| 通配前缀（`http://*`）被误判为精确白名单 | 判定用「**含 `*` 即宽松**」而非「等于 `*`」 |
| 告警刷屏 | 每次启动**一条**（不随请求重复） |

## 4. 验证口径

- **默认行为不变**：既有 4 例（回显任意来源 / 预检 / 最高优先级 / 无 Origin 不加头）**全程保持绿**。
- **新行为**：
  ① 白名单内回显、**白名单外不回显**（否则「收紧」只是摆设）；
  ② 通配判定为**纯逻辑**（可单测：含 `*` 即宽松）；
  ③ 告警文案须含**配置键**与**风险条件**；
  ④ 空配置回退到 `*` 且**仍判宽松**（不得因回退而静默）。
- 退出码三态：`0` 通过 / `1` 断言失败 / `2` 环境前提不成立。
