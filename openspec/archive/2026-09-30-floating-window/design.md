# Design — 浮窗

- 关联 Proposal: 2026-09-30-floating-window/proposal.md
- 创建日期: 2026-09-30

## 1. 架构设计

```
用户右键会话 → 选择「浮窗」→ 主进程创建浮窗窗口（300x400，置顶）→ 浮窗显示聊天内容 → 点击浮窗关闭
```

### 前端改动

| 模块 | 改动 | 职责边界 |
|------|------|----------|
| ChatSession.vue | 右键菜单新增「浮窗」选项 | 用户交互入口 |
| index.js | 浮窗窗口创建/管理逻辑 | 主进程窗口管理 |
| windowProxy.js | 浮窗窗口代理方法 | 跨窗口通信 |

## 2. 接口设计

无新增接口。

## 3. 数据模型

无表结构变更。

## 4. 安全设计

- 浮窗窗口置顶显示，alwaysOnTop: true
- 浮窗窗口无边框，frame: false
- 浮窗窗口可拖动，通过 CSS -webkit-app-region: drag

## 5. ADR

### ADR-001: 浮窗窗口大小

- 状态: 已接受
- 上下文: 浮窗窗口大小如何确定？
- 决策: 固定 300x400
- 后果: 实现简单，与微信浮窗一致

## 6. 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| 浮窗窗口遮挡其他应用 | 中 | 低 | 用户可关闭浮窗 |
| 浮窗窗口无法拖动 | 低 | 中 | 使用 CSS -webkit-app-region: drag |

## 7. 依赖与前提

- 无前置依赖
