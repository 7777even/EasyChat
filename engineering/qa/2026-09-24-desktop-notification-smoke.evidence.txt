== Methodology notes ==
- M1: external ShowWindow(SW_MINIMIZE) left win.isFocused() stuck true (minimized window kept
  activation in this harness); message 1842 was correctly suppressed under that stuck-focus state
  (frame arrived + zero calls). Authentic path = CDP win.restore()/win.minimize() which deactivates
  correctly -> used for all subsequent cases.
- M2: PowerShell alias `diff`=Compare-Object takes precedence over a user function named Diff;
  renamed to Get-ColDiff. Scripts kept ASCII-only (PS5.1 reads UTF-8-no-BOM .ps1 as GBK -> line
  corruption with Chinese comments).
- CDP wrapper is in-memory only (lost on app restart); no repo/runtime config was modified by the harness.
