# Retro — 浮窗

## 做得好

- 复用现有窗口管理基础设施（windowProxy.js），实现高效
- 浮窗窗口特性完整（置顶、无边框、固定大小）
- 前端构建一次性通过，无返工

## 问题

- 浮窗窗口的聊天内容同步尚未实现（浮窗窗口加载的是独立的聊天页面，需要进一步实现消息同步）
- 浮窗窗口拖动需要 CSS -webkit-app-region: drag 支持

## 原因

- 浮窗窗口是一个独立的 BrowserWindow，需要单独处理消息同步
- 拖动功能需要渲染进程配合

## 改进方案

- 浮窗窗口的消息同步可作为后续优化项
- 拖动功能可在渲染进程中添加 CSS 样式
